# الأنشطة والألعاب 🎲

أفكار لتشجيع المشاركة وصناعة لحظات ممتعة أثناء الإيفينت:

## أنشطة

### جدار الذكريات

- **الهدف:** إشراك الحضور في توثيق تجربتهم.
- **التنفيذ:** خصّص مساحة يترك فيها المشاركون رسائل أو صوراً من الإيفينت.

## ألعاب

### تحدّي المعلومات

- **الهدف:** إضافة منافسة خفيفة مرتبطة بموضوع الإيفينت.
- **التنفيذ:** اطرح أسئلة قصيرة على فرق صغيرة وقدّم جائزة رمزية للفريق الفائز.
