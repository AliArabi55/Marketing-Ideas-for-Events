# أفكار تسويقية للإيفينتات 🎉

مساحة بسيطة لجمع أفكار التسويق والفيديوهات الملهمة، من أول التشويق للإيفينت إلى مشاركة لحظاته بعد انتهائه، بالإضافة إلى أنشطة وألعاب للحضور.

## تصفّح الأفكار

- [قبل الإيفينت 🎬](before-event/README.md): أفكار للتشويق وجذب الحضور.
- [أثناء الإيفينت 📸](during-event/README.md): أفكار لتغطية التجربة وتشجيع التفاعل.
- [بعد الإيفينت ✨](after-event/README.md): أفكار لإبقاء أثر الإيفينت حاضراً.
- [الأنشطة والألعاب 🎲](activities-and-games/README.md): أفكار يمكن تنفيذها مع الحضور.

الأمثلة الموجودة نقطة بداية قابلة للتعديل، ولا تتضمن فيديوهات حتى تتم إضافتها.

## كيف أضيف فكرة أو فيديو؟

اختر القسم المناسب وأضف الفكرة إلى ملفه. يمكنك استخدام هذا القالب، مع وضع رابط الفيديو أو مصدر الإلهام إن وجد:

```markdown
### اسم الفكرة

- **الهدف:** ما الذي نريد تحقيقه؟
- **التنفيذ:** كيف ننفّذ الفكرة؟
- **الفيديو أو المصدر:** رابط إن وجد.
```

يمكن إضافة روابط لفيديوهات خارجية أو لملفات داخل المستودع. اذكر المصدر واحرص على امتلاك حق مشاركة أي محتوى ترفعه.
