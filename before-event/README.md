# قبل الإيفينت 🎬

أفكار للتشويق ولفت الانتباه قبل موعد الإيفينت:

### عدّ تنازلي

- **الهدف:** تذكير الجمهور بالموعد وزيادة الترقّب.
- **التنفيذ:** انشر سلسلة فيديوهات قصيرة تكشف تفصيلاً جديداً مع كل يوم يقترب فيه الإيفينت.

### لمحة من وراء الكواليس

- **الهدف:** إثارة الفضول حول التجربة القادمة.
- **التنفيذ:** شارك لقطات من التحضيرات من دون كشف كل التفاصيل.
