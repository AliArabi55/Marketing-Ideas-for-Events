# أثناء الإيفينت 📸

أفكار لتغطية التجربة وتشجيع الحضور على التفاعل:

### أبرز اللحظات

- **الهدف:** نقل أجواء الإيفينت للجمهور.
- **التنفيذ:** صوّر لقطات قصيرة من الفعاليات وانشرها خلال اليوم.

### انطباعات الحضور

- **الهدف:** مشاركة التجربة من وجهة نظر المشاركين.
- **التنفيذ:** اسأل الحضور عن لحظتهم المفضّلة وسجّل إجاباتهم بموافقتهم.
