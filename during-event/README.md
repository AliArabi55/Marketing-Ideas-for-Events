# During the Event

A practical coverage plan for Microsoft Build Talks. Confirm the agenda and assign roles before event day so the team can focus on capturing the experience.

## Coverage ideas

1. **Opening moments:** Attendee arrivals, registration, and the room before the event begins.
2. **Talk excerpts:** Capture one strong, clear 15–30 second takeaway from each session across AI, cybersecurity, project management, and personal branding. Check with speakers and follow venue recording rules.
3. **Quick audience reactions:** Between sessions, ask an optional question such as, “What is the best thing you have heard so far?” Record and publish responses only with the participant's informed consent.
4. **Activities and prizes:** Capture participation and any prize moments only if the activities and prizes have been confirmed. Avoid implying that proposed gifts are guaranteed.
5. **Live stories:** Share timely updates such as the room atmosphere, session transitions, and approved behind-the-scenes moments. Do not publish unverified attendance figures or photos of refreshments as promised event benefits.

## Team responsibilities

| Role | Owner | Notes |
|------|-------|-------|
| Talk recording | | Stable tripod; close shots only where permitted |
| Attendee interviews | | Microphone and prepared questions; ask permission before recording |
| Live stories | | Publish approved updates throughout the day |
| Photography | | Organize approved photos for later posts |

## Quick guidelines

- Do not publish footage of anyone who has not agreed to be recorded or featured. Respect any request to stop recording or remove a clip.
- Confirm speaker, venue, and attendee recording permissions before filming.
- Store raw footage in `raw-footage/`, organized by session and time, and limit access to the event team.
- Check names, session titles, and event details before posting.
